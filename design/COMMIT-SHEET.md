# ChiLab Studio Commit Sheet

## 1. Moment Of Care

The homepage opens like a project ledger that has been pinned to a studio wall: enormous studio name, short factual deck, and a right rail that immediately shows disciplines, contact, recognition, and index counts. The care moment is the project preview behavior on the work index, where the archive becomes scannable without turning into a generic card grid.

## 2. Color

Primary: near neutral warm white `#f4f3ef`, ink `#20201d`, soft rule `#d6d2c8`, oxidized red `#9f3f27`.

Commitment tier: restrained. Most of the surface stays typographic and neutral because ChiLab work is materially loud already. The red is not decorative heat. It behaves like foundry notation: current state, hover state, and a few hard stops.

Background lightness target: 0.91.

Why this is not lavender, cream reflex, or category default: art fabrication sites tend to use portfolio white grids or black luxury voids. This is a working editorial sheet with real project imagery and dense project metadata.

## 3. Type

Display and text: self-hosted Inter Tight variable as a single grotesk family, pushed through scale, weight, and rule structure rather than a decorative pairing.

Why not Inter default: this uses Inter Tight, not standard Inter, and the design leans on compressed grotesk proportion to echo the supplied Neue Grafik reference.

## 4. Grid Break

The homepage breaks the symmetric portfolio grid with a full-width picture ledger: one large feature image spans three columns while a tall stacked caption rail sits beside it. The project cards below stay smaller, so the first image has actual authority.

## 5. Motion Budget

Two patterns:

1. Hover image preview on the work index.
2. Subtle image contrast shift on project links.

No scroll choreography. The site should feel fast, direct, and useful.

## 6. Reflex Check

First-order reflex for a fabrication studio: full-bleed shop photo hero, three service cards, client logo strip, contact CTA.

Second-order reflex: raw brutalist text page with no image hierarchy, pretending austerity is taste.

Chosen deviation: a Swiss editorial project ledger with real images, dense metadata, and capability text that reads like a shop that knows how things are made.

## 7. House Tells Broken

Near-black by default: broken. This is a lit page with black type and material images.

Glow as depth: broken. Depth comes from photography, rule lines, scale contrast, and project sequencing.

Status bar header: broken. Header is a five-column nav, not a logo/status/action strip.
