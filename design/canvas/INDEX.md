# Pamphlet design canvases

One editable canvas per project, each pamphlet sheet an artboard, published as a
private Claude Artifact. Working files live beside this file under `<slug>/`;
regenerate with `python3 make_canvases.py <slug>` then `python3 seed_all.py <slug>`,
and republish the seeded `<slug>-pamphlet.html` to the same URL.

The old dark-serif pamphlets in claude.ai/design are untouched.
